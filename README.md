# 🧩 How I Learn
```
My learning process is simple:

       ↓

       ↓
Write Small Programs
       ↓
Make Mistakes
       ↓
Debug
       ↓
Practice
       ↓
Try Something More Difficult
       ↓
Repeat

I try not to rely only on memorizing syntax.

Instead, I ask:

Why does this work?

What happens in memory?

What happens if I change this?

Can I solve the same problem another way?
```
